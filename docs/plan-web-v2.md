# 纯前端版优化计划（第二份样本）

新样本：`2510.18297v1.pdf` —— ACM 模板、13 页、Letter 纸张、19 张图、497 个矢量图元。
与第一份样本（ACL 模板、A4、几乎无图）差异很大，正好暴露出只对单一模板调过的地方。

## 诊断结果

用 JS 解析器跑新样本，与预期对比：

| 指标 | 实测 | 应有 |
|---|---|---|
| 粗体 span 占比 | **0.6%** | 约 5~8% |
| 识别出的标题 | 10 个 | 30+ |
| 论文大标题 | 判成 `author` | `title` |
| 公式块 | 0 个 | 若干 |

### 根因

pdf.js 对内嵌子集字体**不提供 `bold` / `italic` 标志**（实测全是 `undefined`，
只有未内嵌的标准 Times 才有值），所以只能靠字体名判断。而这篇的命名规范我没覆盖：

| 用途 | 本篇字体名 | 原判据 | 结果 |
|---|---|---|---|
| 粗体 | `LinLibertineTB`、`LinBiolinumTB` | `/Bold\|Medi\|Black/i` | 漏 |
| 斜体 | `LinLibertineTI`、`LinLibertineTBI` | `/Ital\|Oblique/i` | 漏 |
| 公式 | `txsys`、`txexs`、`txmiaX`、`NewTXMI`、`LibertineMathMI` | `/CM(MI\|SY\|EX)\|MS[AB]M\|…/i` | 全漏 |

标题判定完全依赖字重（这是第一份样本教的：字号不可靠，小节标题字号可能小于正文），
所以字重一漏，标题、大标题、附录边界全部跟着错。

## 方案

### 1. 字重判定改为「文档自适应」，不再靠关键词硬匹配

先扫全文收集所有字体名，再按**同族变体**推断样式：

```
LinLibertineTB  去掉尾部 B  → LinLibertineT  （文档中存在）→ 粗体
LinLibertineTI  去掉尾部 I  → LinLibertineT  （存在）       → 斜体
LinLibertineTBI 去掉尾部 BI → LinLibertineT  （存在）       → 粗斜
LinBiolinumTB   去掉尾部 B  → LinBiolinumT   （存在）       → 粗体
```

判据是「去掉尾部的 B/I 之后，剩下的名字也在本文档里出现过」——
比枚举关键词稳，因为它用的是同一份文档内部的证据，而不是我对命名习惯的猜测。
关键词规则保留作为补充（`Bold`、`Medi`、`Black` 等仍然直接判定）。

### 2. 补齐公式字体族

加上 TX 系列与 Math 后缀：`txmi/txsy/txex`、`NewTX*`、`*MathMI*`。

### 3. 复验两份样本

改完必须两份都跑：新样本修好的同时，不能让第一份样本退化。

## 验收标准

## 实际改出来的东西

预想中只要补字体判据，实跑之后又挖出三个只在这份样本上才暴露的错误。

### 1. 字重自适应（原计划内）

`buildFontStyles(names)`：先扫全文收字体名，再按同族变体推断。
关键词规则保留作为补充。效果：

| 指标 | 改前 | 改后 |
|---|---|---|
| 粗体 span 占比 | 0.6% | 5.9% |
| 标题 | 10 | 34 |
| 公式块 | 0 | 16 |
| 大标题 | `author` | `title` |

### 2. 行段合并缺下界 —— 左栏的词被并进右栏

现象：`Abstract` 段变成 `"Abstract and question answering tasks…"`，
`CCS Concepts` 同样被污染。

根因在 `splitByColumn` 的行段分组：只判了 `dx <= 阈值`，没有下界。
右栏 span（x0=53.8）与左栏行段末尾（x1=560）算出 `dx = -506`，
照样满足「不超过阈值」，于是被当成同一行段接了上去。

```js
&& dx >= -Math.max(sp.size, 6)   // ← 补上这个下界
&& dx <= Math.max(sp.size * 0.6, 5)
```

同时把排序键改成 `Math.round(a.baseline)`，避免同一行的浮点基线抖动打乱顺序。

### 3. 栏间空隙判定对两类页面失效

原判据只有一条「中带覆盖率 < 两侧 × 0.35」，两边都会误判：

- **跨栏宽表/大图**：表格横穿中带，覆盖率被抬高 → 整页判成单栏 → 左右栏文字串行
- **稀疏的参考文献页**：中带完全空白（覆盖 0），但两侧内容少（`sides = 2.0`），
  被 `sides >= 3` 的守卫挡掉 → 同样判成单栏

改成两条判据取其一：

```js
const best = widest(0)                          // 中带全空 —— 铁证，与两侧多寡无关
         || (sides >= 3 ? widest(sides * 0.75) : null);  // 或远低于两侧
```

阈值从 0.35 放宽到 0.75，靠下游的「两栏内容量是否均衡」兜底剔除假空隙。

### 4. 跨页重复 = 页眉页脚

新样本每页都有 ACM 的会议名页眉，原来一个都没识别出来（`header_footer: 0`）。
加 `findRunningHeads(pages)`：按「归一化文本 + 取整的 y」聚合，
在至少 `min(3, max(2, 页数/3))` 页的上下边缘带（12%）重复出现才算。
纯数字（页码）单独放行。两个版本同步实现。

### 5. 项目符号行不是标题

`• Information systems → Retrieval models and ranking.` 整行粗体，被判成标题。
加 `RE_BULLET` 检查，放在字重判定**之前**。

## 已知未修

**ACM 的 `[N]` 编号参考文献不会按条拆分。** `mergeReferences` 假设悬挂缩进
（续行比首行更靠右），而这篇所有参考文献行的 x0 都是 53.8，没有缩进差可用。
两个版本同此问题，影响的只是参考文献的分条粒度，不影响正文。
