# 使用指南

[← 返回 README](../README.md)

## 对照阅读

拖一份英文 PDF 进来，或从「最近打开」选一份已解析过的。

左栏是原版页面，右栏是中文，**滚到哪译到哪**，两栏双向同步 —— 滚任意一侧，
另一侧都会对齐到同一段。

栏间那条带子把当前段落在两侧的纵向跨度连起来。中文排版长度约为英文的
0.6~0.8 倍，两栏几何上永远对不齐，带子的收放画出的就是这个长度差。

顶栏「翻译全文」把整篇一次译完，与对照阅读共用同一份缓存 —— 已经看过的页
不会重复付费。

右栏里这些内容保留原文而不翻译：公式、代码块、文档中原本就是中文的段落。
参考文献默认折叠成一条标记，可在设置里打开翻译。

## 难词模式

顶栏切到「难词」。整篇保持英文，超出你词汇量的词加一条虚下划线，并在词后跟
一段简短中文：

```
Social media is an always-on setting for social comparison: users
infer（推论出,推断） standing by comparing with others.
```

**点击**该词（点中文也一样）弹出卡片，含完整释义、音标、词频档位，可收进
生词本。再点一次、点别处或按 Esc 收起。

### 等级基准

两套，在设置里自选：

- **按词频档位** — 认识 COCA 前 3 千 / 5 千 / 8 千 / 1.5 万词
- **按考试大纲** — 中考 / 高考 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE

范围越大，标注越少。判定全程离线，不调用任何 API，不花钱。

自动排除：专有名词（作者名、机构名、模型名）、术语表词条、公式与代码块。
**给不出释义的词不做标记** —— 点开是空的下划线只会打断阅读。

### 生词本

卡片上点「收进生词本」，顶栏「生词本」查看与导出：

- **CSV** — 单词、原形、音标、词性、释义、语境句
- **Anki** — 制表符分隔，导入时选「字段由制表符分隔」，正面是单词，背面是音标、释义与例句

收藏不等于已掌握，收藏过的词仍会继续标注 —— 你正在学它。

难词模式需要本地词库，见[配置指南](configuration.md#难词词库)。

## 导出

顶栏两个按钮，都需要先完成全文翻译（未译比例过高会拒绝并说明还差多少段）。

### 导出 PDF

产出**保留原版式的中文 PDF**：栏数、图片与图表位置、标题层级、页码水印全部
留在原处，只把文字换成中文。公式、代码、表格、原本就是中文的段落原样保留。

输出仍可搜索复制，不是图片。中文字体由 PyMuPDF 自带，不依赖你的系统装了什么字体。

总页数允许变化 —— 译文比原文长的段落会自然溢出。实测 19 页论文导出 28 页。

### Markdown

无条件附带的保底产物：丢版式但内容完整、可二次编辑。版面重建在某些文档上
失真时，至少还有能读的东西。含标题层级、表格与参考文献。

## 重新翻译

译文不理想，或在设置里换了模型，点顶栏「重新翻译」清空已有译文重来。

命中缓存的部分不会重新花钱。要连缓存一起绕过，需要换用别的模型 ——
缓存是按「源文本 + 端点 + 模型」索引的。
